## 🚀 Usage

### Installing

Install Bottery using `pip`:

```bash
pip install bottery
```

### Creating a Project

Create a new project using the Bottery command-line interface:

```bash
bottery startproject librarybot
```

### Running

Start the bot from your project directory:

```bash
bottery run
```
